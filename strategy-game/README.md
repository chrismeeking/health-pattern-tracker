# Command Frontier

A standalone React, TypeScript, and Vite browser strategy game.

This project is intentionally separate from the health tracker app at the repository root.

## Local commands

```bash
npm install
npm run dev
npm run build
```

## Deploy from a hosted service

Use `strategy-game` as the project/root directory.

### Vercel

- Framework: Vite
- Root directory: `strategy-game`
- Build command: `npm run build`
- Output directory: `dist`

### Netlify

- Base directory: `strategy-game`
- Build command: `npm run build`
- Publish directory: `dist`
